01 Variables y tipos de datos 📖 Docs oficiales →

En Dart puedes declarar variables con var (Dart infiere el tipo) o declarar el tipo explícito. Ambas formas son válidas. 

// Tipos básicos
String nombre    = 'Juan';          // texto
int edad         = 20;              // entero
double promedio  = 4.2;             // decimal
bool estaActivo  = true;            // verdadero / falso
List<int> notas  = [3, 4, 5, 4, 3]; // lista (arreglo)

// Con var — Dart detecta el tipo solo
var ciudad = 'Medellín';    // Dart sabe que es String
var numero = 42;            // Dart sabe que es int

// Nulos — Dart obliga a declarar si algo puede ser null
String? apodo = null;       // el ? permite null

void main() {
  print('Hola, $nombre! Tienes $edad años.');
  // Salida: Hola, Juan! Tienes 20 años.
}

02 Ciclos — for, while, for-in 📖 Docs oficiales →

Los ciclos son fundamentales para recorrer estructuras de datos. Aquí los tres más usados: 

void main() {
  List<int> notas = [3, 4, 5, 4, 3];

  // for clásico — con índice
  for (int i = 0; i < notas.length; i++) {
    print('Nota $i: ${notas[i]}');
  }

  // for-in — más limpio, recorre elemento a elemento
  for (int nota in notas) {
    print('Nota: $nota');
  }

  // while — repite mientras la condición sea verdadera
  int contador = 0;
  while (contador < 3) {
    print('Vuelta #$contador');
    contador++;
  }

  // forEach — estilo funcional
  notas.forEach((n) => print('→ $n'));
}

03 Clases — la base de todo nodo 📖 Docs oficiales →

En Estructura de Datos vas a crear tus propias clases todo el tiempo — un Nodo, una Lista, una Pila. Empieza con la más simple: 

// Clase simple — un Nodo de lista enlazada
class Nodo {
  int valor;          // el dato que guarda
  Nodo? siguiente;    // apuntador al siguiente (puede ser null)

  // Constructor
  Nodo(this.valor);
}

// Clase con más funcionalidad
class Estudiante {
  String nombre;
  int edad;
  List<double> notas;

  Estudiante(this.nombre, this.edad, this.notas);

  // Método — acción que puede hacer el objeto
  double calcularPromedio() {
    double suma = 0;
    for (double n in notas) suma += n;
    return suma / notas.length;
  }

  // toString — cómo se muestra el objeto con print()
  @override
  String toString() =>
    '$nombre ($edad años) — Promedio: ${calcularPromedio().toStringAsFixed(1)}';
}

void main() {
  var e = Estudiante('Ana', 21, [3.5, 4.0, 4.5, 3.8]);
  print(e);
  // Salida: Ana (21 años) — Promedio: 3.9

  // Lista de nodos
  var n1 = Nodo(10);
  var n2 = Nodo(20);
  n1.siguiente = n2;   // n1 apunta a n2
  print('${n1.valor} → ${n1.siguiente?.valor}');
  // Salida: 10 → 20
}
